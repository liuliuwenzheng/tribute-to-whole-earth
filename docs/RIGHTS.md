# 版权 · Rights

- 原刊受版权保护。公开提供**全文**（含完整译文）前，应取得权利方许可，或仅使用对方明确允许的方式。  
- 当前公开仓默认内容：总目、说明、流程、结构模板、不含全文的元数据。  
- 全文与译稿：建议放本机或私有位置，许可落地后再考虑公开镜像。  
- 查阅原页：优先链接 [Internet Archive](https://archive.org/) 与 [wholeearth.info](https://wholeearth.info/)。

## 配图 · Figures

- 阅读体验要求：**图随文走，不丢图**。

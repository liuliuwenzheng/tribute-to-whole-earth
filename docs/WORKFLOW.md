# 逐本制作流程 · Volume workflow

目标：像电子百科一样，**一本完整译完再下一本**；**配图不丢**；经验写下来留给后面的卷。

## 硬标准

- **完整翻译**：正文、标题、作者行、图注、表格文字都进中英对照，不摘要糊弄。  
- **配图保留**：每张图有稳定引用（IA 页图 URL 或许可后的 `media/` 副本），中英页都能看见对应图。  
- **经验沉淀**：本卷踩过的 OCR/版式/术语坑写进 `LESSONS.md`，供后面复用。

## 顺序

1. 在 `data/catalog.json` 选定 `slug`（先 Fall 1968）。  
2. 复制 `volumes/_template/` → `volumes/<slug>/`，填 `meta.json`。  
3. **源页**：用 IA `archive_id` 拉页图清单，写入 `media/manifest.json`（公开仓可只存 URL 清单）。  
4. **OCR**：每页文本 → 校对英文全文。  
5. **切片**：工具条目 / 文章 → `entries/*.json`（含 `figures[]`）。  
6. **翻译**：`body_en`→`body_zh`，`title`/`caption` 一并译全。  
7. **配图**：每条 `figures` 对上页码与图注；阅读页左右文、图不断档。  
8. **关联**：`see_also`（跨条目 / 跨期）。  
9. **搜索**：卷内索引；多卷后再合并全集。  
10. 更新 `STATUS.md`，写 `LESSONS.md`。

## 验收（一卷算完成）

- [ ] 主要条目中英全文齐全（非摘要）  
- [ ] 配图与图注齐全、可点开原扫描对照  
- [ ] 目录可浏览，卷内可搜索  
- [ ] 至少一条关联可跳转  
- [ ] 本期署名入卷内 CREDITS  
- [ ] LESSONS 至少记 3 条可复用经验  


## 用语（2026-10-22）

- 阅读与文档统一称「**页**」，不称「叶」。
- 中英翻译必须落在同一条目上严格对应，禁止错配。

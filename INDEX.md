## 单卷目录约定（完整、简单）

```
volumes/<slug>/
  meta.json          # 刊名、IA、状态
  STATUS.md          # 勾选进度
  CREDITS.md         # 本卷署名
  LESSONS.md         # 经验
  media/manifest.json# 全页配图 URL（不丢图）
  entries/*.json     # 全文条目（中英+figures）
```

全文译稿默认在本机工作区；许可后再考虑进公开树。标准：**完整翻译、配图不丢**。
